# API reference

Generated by `scripts/make_api_reference.py` from the application's routes; the access column is read from the real dependencies, so it cannot disagree with the code. Machine-readable schema: `docs/api/openapi.json`. Interactive docs at `/docs` are available in `dev` and `test` environments only.

Authentication: `Authorization: Bearer <JWT>` obtained from `POST /api/v1/auth/login`. Error bodies are `{"detail": ...}`; validation errors are 422, unknown or foreign resources 404, wrong role 403, rate limit 429 with `Retry-After`.
