# Society results (generated)

Generated by `scripts/make_society_docs.py` from the saved evaluation files in `artifacts/society/`. Nothing here is typed by hand. Units: demand in kW (hourly mean, numerically equal to kWh per hour). Test period = the last six months of the data, scored once; the model for each horizon was chosen by mean absolute error over four expanding-window cross-validation blocks that precede the test period (baselines compete in that selection). MAPE ignores hours whose actual demand is below 1 kW. See `docs/society/04_models_and_evaluation.md` for the protocol.
